# Attractor

**Ambient arcade player.** Attractor cycles your MAME collection through each
game's real attract mode — one game every few minutes, embedded in a clean
desktop window with its marquee art — as ambience while you work.

It is **not** a front-end or launcher: games are watched, not played.

> 🚧 Work in progress. v1 is under construction — full README, screenshots and
> installer arrive with the first release.

## Requirements

- Windows 10/11
- Your own MAME (0.147 through current) and your own ROMs. **Attractor ships
  with no MAME, no ROMs, and no artwork, and will never download any.**

## Status

Building toward v0.1: embedded game frame, rotation engine, transport
controls (previous / hold / skip / ban / favorite), global hotkeys, first-run
wizard, installer.
